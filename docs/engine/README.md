## 两份文档的关系

| 位置 | 面向谁 | 进发行包吗 |
|---|---|---|
| [`../`](../README.md) 的根级文档 | 玩家 / 卡带作者 / 内容包作者 / agent | **是**（构建同步到发行目录的 `docs/`） |
