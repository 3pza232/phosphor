# 玩 PHOSPHOR

## 启动

绿色免安装：解压后双击 `phosphor.exe` 即可，不需要安装、不需要运行库。
主机会扫描自己同级的 `carts/`，把找到的卡带摆在卡带架上。

从终端启动时可以带参数（`phosphor.exe --help` 是权威列表）：

```bash
phosphor --cart carts/snake      # 直接进某张卡带，跳过卡带架
phosphor --scan carts            # 只列出扫到的卡带
phosphor --save-dir my-saves     # 把存档写到别处（多份进度互不干扰）
phosphor --log host.log          # 把主机日志落盘（排查问题时有用）
```

## 操作

| 键 | 作用 |
|---|---|
| 方向键 | 移动 / 选择 |
| `Enter` | 确认；游戏里通常是暂停或开始 |
| `Shift` | 卡带自定义（常见是重开） |
| `Esc` | 返回：游戏里打开暂停菜单，菜单里退回卡带架 |
| `F2` | 调试台（帧率、卡带耗时、日志） |

各卡带要用哪些键，它会写在自己的侧栏或画面里；**提示里写的是键盘上真实的键**，
照着按即可。卡带架用方向键选、`Enter` 进入。

## 卡带

- 卡带就是 `carts/` 下的一个文件夹（或一个 `.phos` 包文件），**放着就能被扫到**，
  不需要安装、不需要重启主机。
- 拿到别人的卡带：整个文件夹丢进 `carts/`，或者放一个 `.phos` 文件进去。
- 卡带是沙箱脚本，不会碰你的文件系统与网络。
- 卡带架默认把**最近打开的**排在最前：记录写在主机同级的 `recent.txt`（最多 24 条，
  一行一个卡带 id），没打开过的按扫描顺序排在后面。删掉这个文件就回到目录顺序。

## 存档与磁带码

- 存档在 `saves/<卡带 id>.sav`；卡带只有声明了 `save = true` 才会用到它。
- **磁带码**是把存档变成一串可复制的十六进制文本：在暂停菜单里进入「磁带码」，
  可以查看当前存档的码、也可以把别人的码敲进来导入。换机器、发帖分享进度都靠它。
- 磁带码是纯文本，不依赖主机版本；导入前原存档会被整份替换。

## 设置

暂停菜单里的「设置」能改：皮肤、显像管滤镜、启动动画、音效方案、字体、界面语言、
CRT 强度、音量、卡带架样式。这些设置写进 `config.json`（与 `phosphor.exe` 同级），
删掉它会回到出厂默认；**卡带与存档都不受影响**。

想改主题文件本身、或者做一份自己的主题/语言，见 [content-packs.md](content-packs.md)。

## 常见问题

**卡带没出现在卡带架上？**
确认它在 `carts/` 里、且目录下有 `manifest.lua`（或是一个 `.phos` 文件）。
用 `phosphor --scan carts` 看主机到底认到了什么、报了什么错。

**改了卡带为什么不生效？**
开发目录（仓库）里 `carts/` 由构建时从源码同步而来，存盘即生效。
发行包里 `carts/` 是普通目录，改完直接生效，同样不需要"编译"。

**存档丢了？**
`--save-dir` 指定的目录才是存档目录；不看这个参数时默认是主机同级的 `saves/`。
换机器用磁带码最稳。
