[ TETRIS —— 俄罗斯方块 ]

七种方块落进 10×20 的井：左右移动、上/X 顺时针旋转、Z 逆时针旋转、
下加速下落、Space 硬降、Enter 暂停、Shift 重开。
消满一行得分，每十字升一级、落得更快；最高分自动存档。

模块
  main.lua     入口：生命周期、输入、分层绘制
  game.lua     棋盘与规则（状态转移，不碰画面）
  panel.lua    侧栏：分数 / 等级 / 下一块 / 操作提示
  sfx.lua      音效      music.lua  背景音乐
  scores.lua   最高分存档

这份卡带是**图层（phos.layer）**的出厂样板，四层的分工见 main.lua 顶上那段注释：
井与已落定的方块画在底层，下落中的方块、特效、浮窗各占一层。
不建层的卡带写法与本卡带的底层完全相同 —— 分层是想分开时才取用的能力，
见 docs/api-reference.md 的 `phos.layer` 一节。

观测口
  debug_state() 报出棋盘逐行（每行 10 个字符，`.` 为空）、当前块与落点投影、
  下一块、分数等级。agent 据此可以自己算"这块该放哪"，不必读画面反推。
