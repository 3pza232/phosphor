[ WORMS —— 回合制炮击 ]

你指挥一队虫子，在**可破坏的大地图**上用抛物线把对面的虫子轰进海里。
一回合 60 秒、一次只能开一炮；风、天气与空投补给都会影响战局。
数值、字段与算法以 dev/DESIGN.md 为准（本文件只做导读）。

操作（对局中按 K 弹出完整键位表；下面写的是键盘上真实的键）
  左右      走路（进入蓄力后改为调力度）
  上下      调角度（可达 -60°，朝下打）
  A         进出蓄力状态（蓄力时走不动，力度保留）
  空格      按当前力度发射
  X / Z     下一件 / 上一件武器
  B         跳跃
  , . ' /   镜头左右 / 上下平移
  M         地图总览（不暂停，弹药在飞时也能看一眼）
  K         键位表（暂停）              回车  结算后回菜单        Esc  返回卡带架

模块（每块只做一件事）
  manifest.lua  卡带身份（sidebar 22 格、save = false、phos_api = 4）
  main.lua      总装配：模式菜单、输入翻译、绘制、跨模块取舍、agent 观察口
  terrain.lua   地形：生成 / 破坏 / 查询（不碰虫子与物理）
  physics.lua   重力 / 风 / 子格步进 / 碰撞 / 爆炸 —— **唯一物理真源**
  worms.lua     虫子状态机：走 / 跳 / 坠落 / 受伤 / 死亡（不读键盘、不绘制）
  weapons.lua   武器表 + 通用发射器（数据驱动；plan / effect / ai 三段描述）
  turn.lua      回合、计时、胜负
  ai.lua        电脑队决策：按 plan×effect 装配，评分只认"世界变化量"
  camera.lua    滚动、夹紧、世界↔字符格换算
  weather.lua   时钟、天色、日月云星（背景）、风痕与降水（天气层）
  supply.lua    空投补给：落下 / 落地 / 领取 / 过期、AI 可达性判据
  hud.lua       顶部读数：角度 / 力度 / 风 / 倒计时 / 时钟天气 / 伤害浮字
  panel.lua     侧栏：两队血量 / 武器网格 / 地图与键位提示
  music.lua     曲式化背景乐（乐段 + 曲序）
  assets/       分语言文本示例（motd.zh.txt / motd.en.txt，取不到回落 motd.txt）

分层绘制（main.lua 的 draw，详见 dev/DESIGN.md 第 9 节）
  世界（天空 + 地形 + 水）直接写 phos.screen 底层；其余按**类别**各占一层、按 z 升序叠：
  fx 特效 → aim 瞄准线 → actors 角色 → weather 雨雪风痕 → hud 读数 → overlay 浮窗。
  同类的东西不再互相擦除，且层是**按像素**叠上去的（笔画之外透出下层）。

观测口 debug_state()
  报出屏幕态、回合 / 风 / 时钟 / 天气、两队逐只位置与血量、当前武器与余弹、
  相机原点，以及光柱 / 激光 / 补给 / 传送等实况 —— agent 据此算弹道、判命中，
  不必读画面反推地形。
