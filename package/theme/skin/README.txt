[ theme/skin - 游戏机主题（机身外壳） ]
========================================

每个子文件夹 = 一套风格。这个文件夹名，就是设置界面里显示的名字
（改文件夹名就是改显示名；没有第二套命名，也不需要 manifest）。

现有：
  default        出厂机身 P-1（极简工业风，双灯柱 + 铭牌）——可以直接改它
  rust-cabinet   废弃游戏厅的机台
  neon-husk      霓虹残壳
  ivory-terminal 象牙白实验仪器（暖白机身 + 琥珀高亮）
  crimson-arcade 红白街机机台（深红机身 + 金色高亮）
  graphite       石墨灰工程终端（细线冷灰）
  eva-unit01     初号机配色（紫机身 + 荧光绿高亮 + 橙色警戒）

一套主题决定什么：
  * 内容区（"屏幕"）在网格中的**位置**（尺寸由主机固定为 80x45，皮肤不参与决定）
  * 机身边框的字符画、指示灯位置与呼吸节奏
  * 卡带架 / 设置 / 暂停等系统界面的配色
  * 内容区**色板**（skin.lua 里 `palette = "<名>"`，指向 theme/palette/ 下的一套；
    卡带与开机动画的 `phos.color.*` 与默认前景/背景都随之变）

怎么做：复制 default 文件夹，改名，然后编辑 skin.lua（必需的唯一文件）。
      首行注释写下这套风格的一句话说明，别人打开文件夹就看得懂。
      字段规范见 docs/content-packs.md。

兜底：本目录下一套主题都没有时，使用 system/skin/ 中的出厂包（若有），
      再没有就用主机内建机身。所以删掉主题也不会开不了机。
