[ theme/font - 字体方案 ]

每个子文件夹是一套**字体方案**，可在设置里切换；文件夹名即方案名，出厂默认是 default。

方案内的文件按**角色名**区分（扩展名 .ttf / .otf / .ttc 均可，TTC 取第 0 号）：

  theme/font/default/font.ttf       角色 font    —— 主字体：ASCII 与整机字形风格
  theme/font/default/font-cn.otf    角色 font-cn —— 回退：补齐主字体缺的码位（中文）

取字规则：

- 主字体 font.* 排最前，其余 font-* 回退按名称排序在后，依次取第一个含该字形的字体。
  "英文看 font、中文看 font-cn" 就是这套命名的由来。
- 方案里没有名为 font 的文件时，取名称排序后的第一个当主字体（仍能显示，风格随该字体）。
- 字形缺失时依次向回退要字形；都没有则显示 '?'，不会留空格。
- 坏字体文件被跳过并告警，不会让整机没字可用。
- 方案缺失或装不出字体：退回 default 方案并告警，绝不因此开不了机。

方案声明（可选）：`theme/font/<方案>/font.lua`

- 不写也完全可用——不写时按上面的文件名规则取字。
- 写了可显式声明两件事，不必靠文件名表达意图：

  return {
    size = 16,                     -- 方案默认字号 = 单元格像素边长（行距随之变）；12~24
    order = { "font", "font-cn" }, -- 回退顺序，按 stem 或文件名；首个为主字体
  }

- `order` 里没列到的字体文件按文件名规则**附在其后**，绝不静默丢字。
- `size` 是方案建议的字号；用户在设置里可选 12~24 覆盖它（默认 16）。
- **字号 = 单元格像素边长**：整机字符大小随之缩放（行距 = 格高），不是"字形在固定格内缩小"。


两套度量（改之前先看清）：

- 主字体按行高缩放（ascent − descent = 格子高），整机像素基线由它确定；
- 回退字体按 **em 方框** 缩放，并用 OS/2 排版度量对齐基线 —— CJK 字体的行高度量普遍
  大于一个 em，若也按行高缩放，汉字只占约 0.7 格，看上去明显偏小。

出厂随附一套方案：

  default/   font.ttf + font-cn.otf（思源黑体 SC）

想换中文观感：复制 default/ 成新目录，换掉里面的字形文件，再切到该方案即可。
切换入口在设置里：SETTINGS → FONT SCHEME 行左右切换，立即生效并写回 config.json。

字体文件版权自负：随仓库分发字体前先确认授权。
