[ dev - 卡带开发产物（不随卡带分发） ]
=====================================

这个文件夹是给**开发期**用的：测试脚本、运行日志、截图、报告、临时存档都放这里，
别散在运行目录（build/）的根下。

  * 主机运行时只认卡带的 .lua（manifest.lua + entry 与它们 require 的模块），
    这个文件夹会被忽略，不影响加载与运行。
  * 但 `phosphor --pack` 会把卡带目录整个打进 .phos —— 所以**打包前把 dev/ 移走
    或删掉**（或写进 .gitignore）。
  * 测试请用 `--save-dir` / `--config` 指到本文件夹下的临时路径，别写进运行目录的
    saves/，也别覆盖运行目录的 config.json。

一句话：一张卡带 = 一个自洽的文件夹，代码、工具、痕迹都在里面。
详见 docs/devkit.md 的「工程习惯」一节。
